1. 报送 / 换报

按月份、资源号、馆号上传 JSON。同一馆再次上传即为换报，整行覆盖旧摘要。 JSON 需含 month、resource、branch、 registers（128 个 0～58 的整数）。

2. 撤回报送

撤回只删除本馆摘要并增量重算合并结果，不遍历其他馆的摘要。

3. 下载已保存的合并摘要

按月份和资源号下载逐位置取最大值后的合并 JSON（无报送记录时返回 404）。 该入口现在也会出具凭据并在 JSON 中附带 credential_id。

4. 下载带凭据号的合并 JSON（出具凭据）

按月份和资源号出具凭据：下载的 JSON 带 credential_id， 服务端在同一事务内留存当时 128 个寄存器各自的最大值与全部报出馆号。 即使之后最大值不变而报出该值的馆发生更换，本凭据仍可按原样查证。 凭据保存失败时不会返回带号文件。

5. 按凭据号 + 寄存器位置查证来源馆

输入下载文件中的 credential_id 与寄存器位置 （0～127），可查凭据出具当时该位置的最大值以及报出该值的所有馆号； 值为 0 时显示空名单。查证只读不可变快照，不读取各馆现行摘要。
